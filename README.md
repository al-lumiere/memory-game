# Memory Game

A browser memory game where the player finds matching pairs of cards in as few moves as possible.

## Deploy

https://al-lumiere.github.io/memory-game/

## Features

- 16 cards / 8 pairs
- random shuffle on every game
- move and pair counters
- victory modal
- leaderboard with top 10 results
- results saved in localStorage
- responsive layout

## Run locally

1. Clone the repository:

   ```bash
   git clone https://github.com/al-lumiere/memory-game.git
   ```

2. Switch to the `memory-game` branch:

   ```bash
   git checkout memory-game
   ```

3. Open `index.html` with Live Server or another local development server.
